Untuk berkontribusi dalam catatan ini, anda dapat mengikuti langkah-langkah berikut ini:

1. Install [Obsidian](https://obsidian.md/download) di perangkat (windows, mac, ios, android)
2. Download file `.zip` [berikut ini](https://drive.google.com/drive/folders/14JRzhyIwqbpAx9PCT7z0UfjG5BDyKPNz?usp=sharing)
3. ekstrak `.zip` ke folder mana pun yang anda tuju
4. buka aplikasi obsidian
5. di dalam aplikasi, pilih `open folder as vault`
6. arahkan ke folder yang diekstrak dari file `.zip` tadi
7. kemudian centang pilihan `I trust this vault`
8. beres, *all set*

anda bisa menambahkan catatan berdasarkan kategori folder yang sudah dibuat. jangan lupa untuk memberikan judul khusus dan tanggal, agar lebih memudahkan untuk mengorganisirnya, dengan cara sebagai berikut:

1. open command atau klik icon ![[image.png]] atau `ctrl+p` 
2. ketik `lint the current file`
3. lalu isi *properties* yang sudah tersedia
